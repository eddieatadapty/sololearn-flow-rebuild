# Sololearn Growth Audit

**Live → https://eddieatadapty.github.io/sololearn-flow-rebuild/**

Five ideas to turn more Sololearn users into subscribers, each built into a clickable version of Sololearn's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Use the answers you collect | +10–20% CR to trial |
| 02 | Say what Pro changes, and say the price as a price | +10–20% CR to trial |
| 03 | Let them finish a real lesson first | +5–15% CR to trial |
| 04 | Show the proof you already have | +5–10% CR to trial |
| 05 | Catch the people who close the paywall | +3–8% CR to purchase |

Every price, rating and feature comes from Sololearn's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Sololearn. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
